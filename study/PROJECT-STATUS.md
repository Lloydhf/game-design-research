# Project status — 24 September 2026

The Unity repository has developed from a movement exercise into two playable prototypes: **Polar Relay**, using magnets and a ball, and **SHIFT — Mass Protocol**, using light/heavy robot modes and route preparation. The original exercises remain available in that repository.

This creates more material for future game-design questions, but it does not supply evidence for the [existing onboarding pilot](PROTOCOL.md). No real participants have completed that study; the data template remains empty. Game logic tests, automated traversal and developer feedback must not be imported as participant sessions or used to claim improved clarity, completion or retention.

## Before choosing a study build

1. Select one stable segment and target within one game. Comparing SHIFT with DASHER would change much more than instruction timing and would not answer the existing question.
2. Implement both instruction-timing variants with the same text, geometry, controls, mechanism behavior and reset rules.
3. Verify the clock and event definitions against the protocol. SHIFT's in-game elapsed time, mode changes and respawn counters are development feedback; they do not constitute the study's consent, allocation or data-collection system.
4. Record the build commit and any dated protocol amendment before recruitment. A SHIFT-specific mechanism study would require an explicit adaptation, not silently replacing the parkour task.

The next useful output is a stable, instrumented test build and a recorded pilot procedure. There are no empirical results to add to the essay at this time.
